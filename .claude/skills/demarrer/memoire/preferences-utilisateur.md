À compléter à l'étape E0 de `/demarrer`, avec la date :
- Forme d'adresse : (vouvoiement / tutoiement)
- Appliquer soi-même les migrations après validation du plan : (oui / non)

**Why:** l'utilisateur a répondu explicitement à ces questions ; les reposer à chaque fois l'agace, les présumer serait abusif.
**How to apply:** respecter ces choix ; une autorisation ne vaut que pour l'action décrite (appliquer une migration ≠ supprimer des données) ; en cas de doute, redemander. Voir [[migrations-methode]].
